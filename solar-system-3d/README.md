# Erfan Space — منظومه شمسی سه‌بعدی

کاوشگر سه‌بعدی و تعاملی منظومه شمسی با رابط فارسی.

## امکانات
- مدل‌های کروی با بافت‌های رویه‌ای و نورپردازی سه‌بعدی
- کلیک روی سیاره یا انتخاب از فهرست برای نمایش نزدیک و اطلاعات فارسی
- دنبال‌کردن سیاره انتخاب‌شده هنگام حرکت مداری
- کنترل سرعت، توقف حرکت، نمایش نام‌ها و مدارها
- کنترل دوربین با ماوس، لمس و اسکرول
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## اجرا
فایل `index.html` را با اتصال اینترنت باز کنید؛ کتابخانه Three.js از CDN بارگذاری می‌شود.

این پروژه یک نمایش آموزشی است؛ اندازه‌ها و فاصله‌های مداری برای دیده‌شدن بهتر مقیاس‌بندی شده‌اند.
