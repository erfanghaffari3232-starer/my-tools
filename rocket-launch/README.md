# Erfan Rocket Launch

A lightweight, self-contained Persian HTML canvas simulation of a fictional educational rocket launch and ascent into space.

## Run
Open `index.html` in a modern browser. No build step, external library, or remote image download is required.

## Features
- Animated countdown from 10
- Canvas-drawn rocket, Earth horizon, stars, exhaust flame, and smoke
- Simulated altitude, speed, and mission timer
- Pause, resume, and reset controls
- Responsive Persian RTL interface

## Note
This is a visual educational simulation. Telemetry values are illustrative, not real flight data. It does not model construction, targeting, or operation of a real weapon or launch vehicle.
